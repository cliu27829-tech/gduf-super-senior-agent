# 最终交付缺陷日志

## DEF-001：真实地图被 WebService Key 错误阻塞

- 状态：FIXED。
- 根因：前端把可选的 WebService Key 纳入真实地图 P0 门禁。
- 修复：真实底图只要求 `VITE_AMAP_JS_KEY` 与后端安全代理；地址解析、校区锚点和步行路线可使用 AMap JS API，WebService 仅作增强。
- 回归：真实浏览器验证 AMap 网络响应、可见底图、地理编码 Marker、详情抽屉、地址步行路线、距离/时间/步骤和三校区切换，1 项通过。

## DEF-002：私有知识导入闭环缺失

- 状态：FIXED。
- 根因：旧范围只有共享知识查询，没有私有来源、分块、任务、去重和权限模型。
- 修复：新增文件/正文/URL 导入、解析、清洗、SHA-256 去重、中文 BM25、来源详情、重建索引、导入任务、私有隔离、管理员审核及对应页面。
- 回归：后端覆盖文本、PDF、去重、搜索、SSRF、隔离和审核；浏览器覆盖导入、重复提示、搜索、来源、删除、账户清理及真实授权 PDF。

## DEF-003：Agent 缺少知识导入意图和工具

- 状态：FIXED。
- 根因：意图与工具契约扩展后，分类器、计划器和工具注册表仍停留在旧版。
- 修复：增加 `knowledge_search`、`knowledge_import`，以及知识文件/正文/URL 导入、搜索、详情和重建工具；写操作必须显式确认。
- 回归：Agent 单元测试验证分类、规划、权限、工具结果、来源和结构化地图动作。

## DEF-004：饭堂 E2E 要求模型输出“当日菜单”

- 状态：FIXED。
- 根因：旧断言要求固定成功文案，与“没有实时数据时不得编造今日菜单”冲突。
- 修复：断言改为验证历史/待核验警示、来源卡片，并明确拒绝“这是今天的菜单”等伪实时表述。
- 回归：真实 DeepSeek 回答明确指出资料来自历史记录且不代表当前经营，整站 E2E 通过。

## DEF-005：管理员 E2E 被外部字体加载拖到超时

- 状态：FIXED。
- 根因：`page.goto()` 默认等待全部资源；受限网络中的外部字体请求长期不结束，而 SPA 已正常渲染。
- 修复：关键 SPA 跳转使用 `waitUntil: "commit"`；共享状态用当前登录用户的真实 API 响应验证；清理直接使用本次导入返回的文档 ID。
- 回归：管理员审核 E2E 3.1 秒通过；测试管理员、资料拥有者和文档全部清理为 0。
