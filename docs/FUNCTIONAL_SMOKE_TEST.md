## 已知环境限制

本机没有 `docker` 命令，因此本地无法实际执行 `docker compose up --build`。仓库 CI 的 delivery job 已增加 Compose 构建、启动和 `/health` 探测；Docker 是否通过以本次 PR 的 GitHub Check 为准。此项在 Check 成功前不能描述为已本机验证。
