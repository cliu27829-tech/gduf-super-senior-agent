# 完整网站审计

审计日期：2026-08-03。审计对象为改造前的 Streamlit 项目及当前 Git 分支、PR #1、数据文件、测试、文档和可遍历历史。

## 改造前结论

原项目是功能较丰富的 Streamlit 演示，但不是可长期使用的网站：页面和数据库耦合；用户身份主要依赖会话；SQLite 任务无法形成正式多用户认证体系；管理入口依赖部署层令牌；前后端不能独立部署；移动端是旧 Capacitor 包装；没有标准 Refresh Token、RBAC、PostgreSQL 迁移、React 页面或全栈 CI。

可以复用的部分包括中国时间解析、通知拆解、ICS、地点/饭堂结构、来源与新鲜度概念、Agent 工具边界和历史测试。旧代码已完整移动至 `legacy_streamlit/`，运行时不再由新网站引用。

## 逐项发现与处置

| 范围 | 审计发现 | 当前处置 |
|---|---|---|
| 页面 | 7 个 Streamlit 页面，刷新与路由体验不适合正式站点 | React 19 SPA，含首页、认证、工作台、对话、地图、饭堂、通知、任务、个人中心和分离后台 |
| Agent | 旧路由含规则匹配，模型和工具结果展示受 Streamlit 限制 | LLM 结构化 JSON 为正常路径，Pydantic 校验；规则仅降级；工具结果/来源为结构化卡片 |
| 通知 | 已有规则、时间与 ICS 能力 | 迁入后端服务；解析不写库，用户确认后才创建任务；TXT/PDF、5 MB 限制 |
| 身份 | 没有正式账号体系 | Argon2、Access/Refresh JWT、HttpOnly Cookie、撤销、账户隔离与角色权限 |
| 数据库 | SQLite 和手动/运行时建表适合 Demo | SQLAlchemy + Alembic；PostgreSQL 正式支持，SQLite 仅快速测试 |
| 地图 | 示意坐标与外部导航，不是测绘地图 | 保留诚实标识；按校区/分类搜索、详情/来源/纠错；不宣传校内路线算法 |
| 饭堂 | 数据少且多为历史/待核验 | 结构化饭堂/档口；禁止未核验餐品进入食物搜索；显式关闭今日菜单 |
| 办事数据 | 完整度有限 | 独立表与 API；Agent 只返回 `verified` 流程；后台可补充和停用 |
| API Key | 旧版支持会话输入 Key | 首页不再输入 Key；仅服务器环境变量读取，不写数据库和响应 |
| 日期 | 有 2025 历史线索及相对日期风险 | 不改写年份；中国时间集中处理；不确定日期要求确认 |
| 后台 | 旧后台不是正式 RBAC | 后端管理员角色强制校验；管理实体、审核、导入导出和审计日志 |
| CI/部署 | 无完整全栈流水线 | GitHub Actions、双 Dockerfile、Compose、健康检查与部署文档 |
| README | 描述仍以 Streamlit 启动为主，部分能力容易被理解为正式服务 | 已重写，准确说明数据量、非实时能力、部署状态和限制 |

## 数据审计

- 广州：4 个地点，2 个待核验、2 个过期；1 条未核验档口线索。
- 肇庆：3 个地点，全部待核验；无档口记录。
- 清远：3 个地点，全部待核验；无档口记录。
- 总计没有可证明为“2026 最新实时菜单”的数据，也没有经测绘的校内路线数据。
- 种子文件中出现历史年份时继续保留原年份和状态，不做机械替换。

## 安全审计

检查了工作区、跟踪文件和当前可遍历 Git 历史中的 `sk-`、GitHub Token、`.env`、`secrets.toml` 与常见敏感字段，没有发现真实凭据。没有重写公共历史。新实现不记录密码、Token、DeepSeek Key 或完整私密通知；系统错误日志只记录异常类型和 request ID。

## 仍需外部完成

代码层缺口已经收敛。线上 URL 的唯一外部阻塞是本机尚未登录部署平台；真实校园数据仍需管理员取得学校或现场证据后核验。线上发布前还需在目标平台创建 PostgreSQL、填入生产 Secrets 并运行在线冒烟清单。
