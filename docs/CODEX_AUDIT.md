## 已确认的问题

### 时间与日期

- 没有统一的 `Asia/Shanghai` 时间服务。
- `tools/ics_tool.py` 和 `tools/csv_tool.py` 直接调用无时区的 `datetime.now()`。
- 缺少年份的日期会静默使用系统年份；如果推断结果已经过去，不会降置信度或请求确认。
- 三个页面的搜索关键词写死 `2026` / `2026年`，没有向模型动态注入当前中国标准时间。
- ICS 使用 naive datetime，未声明 `TZID=Asia/Shanghai`。

### 数据与时效

- 248 篇本地文本资料中，139 篇提及 2024、105 篇提及 2025、46 篇提及 2026；同一文件可能跨多个年份。
- 55 篇资料包含“最新、近期、当前、今天、今日”等时效性措辞，但检索层没有发布时间、抓取时间、核验时间或过期状态。
- 247 篇资料包含外部链接，但链接没有被解析为结构化来源记录；资料也没有官方等级、适用校区和可信度字段。
- 本地资料主要来自公众号文章转存，部分正文依赖图片。现有加载器只读顶层 `.md/.txt/.html` 文本，无法从 4,393 张图片提取事实。
- `build_knowledge_context()` 只显示文件名，可能把历史公众号文章包装成当前参考资料。
- 抓取工具只硬编码清远校区官网；没有多校区来源配置、重试、缓存、差异记录或失败保留机制。

### 地图、地点与饭堂

- 没有 `CampusLocation`、饭堂、档口、来源、核验记录或反馈数据模型。
- 没有校区隔离的数据存储；三个页面靠提示词约束校区，无法从数据层阻止跨校区混用。
- 没有地图页面、坐标、分类筛选、附近搜索、导航链接或无 API Key 降级方案。
- 饭堂相关资料是非结构化公众号文章，不能可靠回答楼层、档口、餐品、营业时间和今日菜单。
- 当前系统没有“今日菜单”和“最近核验档口”的语义区分。

### Agent 与工具调用

- 路由主要依赖关键词 `if/elif`，不是统一的意图、工具计划和执行编排器。
- 页面会先调用通用大模型，再以关键词触发 ICS/CSV/微信工具，存在模型回答与工具事实不一致的风险。
- 地点问题没有本地结构化工具；模型仍可能使用通用知识或搜索摘要作答。
- 有副作用的任务创建没有预览与用户确认阶段。
- 通知任务只生成下载文件，不持久化、不支持查询或完成状态。

### 安全与隔离

- 首页和三个校区页面把用户输入的 API Key 写入进程级 `os.environ`，会污染同进程其他会话。
- 页面会话只有 Streamlit session state，没有持久化用户标识或数据库级隔离。
- `app.py` 强制要求用户填写性别才能进入。
- `deploy.py` 会修改全局 Git 用户配置，不适合作为应用部署流程。
- 移动端 WebView 写死明文 HTTP 地址 `http://136.175.178.35:8501`。

### 重复与维护性

- 三个校区页面各约 462 行，除校区文案外高度重复；任何修复都必须复制三次。
- 固定输出文件 `gduf_tasks.ics` 与 `gduf_expenses.csv` 会造成并发覆盖和用户间串数据。
- `rag/knowledge_base.py` 使用 `FakeEmbeddings`，检索结果不可用于可靠语义匹配。
- `mobile/node_modules/` 被提交（1,577 个文件），仓库体积和供应链审计成本异常高。

## 数据分类基线

在本次重构前，现有知识资料默认按以下规则处理：

- 明确由 2026 官方公告发布、且仍在有效期内：候选“当前有效”，仍需提取来源与发布日期。
- 2025 或更早、涉及菜单、营业、档口、宿舍、课程、交通、活动、商业推广：默认“已过期”或“历史参考”。
- 跨年份的制度、建筑和固定地点资料：默认“需要核验”，不得仅凭旧年份改写成 2026 现状。
- 没有可解析发布时间或官方来源：默认“需要核验”。
- 商业推广、普通网页和未审核学生信息：不得标为学校官方信息。

旧资料不删除；运行时为其补充来源等级、新鲜度、警告和核验状态。

## 重构目标

1. 建立中国时区时间服务和可注入 `reference_time` 的解析接口。
2. 建立地点、饭堂、档口、来源、版本、刷新日志和反馈模型。
3. 用 SQLite 持久化任务与校园数据，所有查询强制校区过滤。
4. 建立本地工具优先的统一编排器，大模型只解释工具结果。
5. 抽取三个校区共享页面逻辑，移除强制性别和进程级密钥写入。
6. 增加地图、管理员核验、数据导入、回滚、过期提醒和来源展示。
7. 增加时间、地点、路由、地图、数据源和任务闭环测试。
