# 用户使用说明

## 账号与校区

注册需要用户名、邮箱、密码和所属校区，年级与专业可选。注册成功后自动登录；关闭浏览器后可用 Refresh Cookie 恢复会话，失效时重新登录。个人中心可改昵称、校区、年级、专业和密码，也可删除账户。

## 查校园与饭堂

地图页先选择广州、肇庆或清远，再按分类/关键词筛选。示意点不是测绘坐标；详情会显示来源、核验状态、更新时间与外部高德导航。发现错误可提交纠错。

饭堂页展示已记录楼层、时间、支付方式、档口和常见餐品。当前没有今日实时菜单；常见餐品也不代表当天供应。食物搜索只返回已核验档口，没有记录时明确说明。

## 通知转任务

1. 粘贴通知或上传 UTF-8 TXT/PDF（最大 5 MB）。
2. 查看标题、截止时间、地点、材料、提交方式、置信度和日期解释。
3. 修改不准确字段；日期不确定时先人工确认。
4. 点击确认后才写入任务数据库。
5. 进入任务中心编辑、完成、重开、删除或批量操作。
6. 下载 ICS 导入系统日历；默认提前 24 小时和 3 小时提醒。

图片 OCR、邮件、短信和浏览器 Push 尚未启用。只有把 ICS 导入日历后，系统日历才可在网站关闭时提醒。

## 问大师兄

可询问地点、饭堂、办事、任务、学习和校园生活。地点/饭堂/流程会显示工具结果与来源。若模型未配置或失败，页面显示规则降级；这不影响数据库查询，但自然语言理解会较基础。

## 隐私

密码不会明文保存；浏览器不在 localStorage 保存 Token。任务与对话按账户隔离。通知内容用于生成本人任务；删除账户会删除关联个人数据。不要上传包含无关人员敏感信息的通知。
