# 线上冒烟测试

部署后记录公开前端 URL、后端 URL、Commit SHA、测试时间与执行人。所有失败项必须保留截图/request ID，不得把 localhost 结果填作线上结果。

## 基础与认证

- [ ] `GET /health` 200，`GET /ready` 200，HTTPS 有效。
- [ ] `/`、`/register`、`/login` 直接打开和刷新无白屏。
- [ ] 新用户注册广州校本部并自动进入工作台。
- [ ] 登出后受保护页跳到登录；重新登录成功。
- [ ] Access 过期后 Refresh Cookie 轮换且请求恢复。

## 地图与饭堂

- [ ] `/map` 切换三校区，结果不混用。
- [ ] 搜索饭堂/教学楼，打开详情与来源，外部导航目标正确。
- [ ] 提交纠错后后台出现 pending。
- [ ] `/canteens` 显示楼层/档口状态；搜索不存在食物不编造。
- [ ] 页面明确没有实时今日菜单。

## 通知、任务与持久化

- [ ] 粘贴含日期通知，先出现可编辑预览，未确认不写库。
- [ ] 上传 TXT/PDF；错误格式和 >5 MB 得到友好提示。
- [ ] 确认后任务出现，可编辑、完成、重开、删除和批量操作。
- [ ] ICS 文件名唯一，可重新解析，含 Asia/Shanghai 与 24h/3h 两个 VALARM。
- [ ] 退出、关闭浏览器、重新打开并登录，原任务仍存在。

## Agent

- [ ] 地点、饭堂、通知、任务、办事、学习、生活意图均返回合理类型。
- [ ] 工具结果不是单一大段文字；来源、时间和降级状态可见。
- [ ] 临时移除 DeepSeek Key 后规则降级，不产生 500、不编造校园事实。

## 管理与权限

- [ ] 普通用户访问 `/admin` 被跳转，访问 `/api/admin/dashboard` 返回 403。
- [ ] 管理员修改地点并填写证据/备注，前台刷新可见，审计日志存在。
- [ ] 未填写 evidence 不能标记 verified。

- [ ] 375、768、1280、1440px 无页面级横向滚动、遮挡或不可点按钮。

- [ ] 浏览器控制台无严重错误；API 失败有可见提示和 request ID 可追踪。
