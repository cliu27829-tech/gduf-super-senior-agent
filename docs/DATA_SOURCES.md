## 来源等级

1. 学校/校区官方网站、正式文件；
2. 管理员现场或电话核验（须记录证据）；
3. 审核后的学生投稿；
4. 有出处的历史资料；
5. 普通网页线索；
6. 演示/待核验数据。

每条来源保存发布、获取、核验时间、发布方、URL、官方标识与可信度。实体另存核验方法、核验人、新鲜度、校区与启用状态。前台不把低级来源隐藏成确定事实。

## 时效规则

从未核验或距离核验超过 180 天的地点进入后台陈旧列表。实际时效仍取决于数据类型：临时通知应更短，建筑位置可更长。系统不自动把年份改新，也不因抓取成功自动标为已核验。

## 导入

模板位于 `data/import_templates/`：CSV 用 `|` 分隔数组；JSON 使用 `locations` 数组；GeoJSON 使用 Point 的 `[longitude, latitude]`。所有外部导入默认建议 `needs_verification`，再由管理员逐条核验。
