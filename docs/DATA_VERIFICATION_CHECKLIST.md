# 三校区数据核验清单

## 通用字段

- [ ] 所属校区正确，没有跨校区复用 ID 或坐标。
- [ ] 名称、别名、分类、区域、楼层准确。
- [ ] 经纬度来自可靠地图/测绘；示意坐标明确标为 schematic。
- [ ] 开放时间、电话、服务和支付方式有独立证据。
- [ ] 来源 URL、发布方、发布日期、获取日期完整。
- [ ] 核验时间、方法、核验人、可信度与证据完整。
- [ ] 超过有效期时改为 expired，失效时停用。

## 广州校本部

- [ ] 复核 4 个种子地点，其中 2 条当前过期。
- [ ] 复核两条饭堂地点的楼层、开放时间和支付方式。
- [ ] 唯一档口历史线索需现场或官方证据；核验前不得进入食品搜索。
- [ ] 补充图书馆、宿舍、快递、医务室、超市等完整分类。

## 肇庆校区

- [ ] 复核 3 个种子地点，当前全部待核验。
- [ ] 核验饭堂楼层、档口、常见餐品和营业状态。
- [ ] 补充宿舍、教学楼、快递、医务室和服务点。
- [ ] 取得有授权的校园地图或可靠 GPS 点位。

## 清远校区

- [ ] 复核 3 个种子地点，当前全部待核验。
- [ ] 核验饭堂和教学楼位置，不与其他校区数据混用。
- [ ] 补充宿舍、图书馆、快递、医务室和服务点。
- [ ] 取得有授权的校园地图或可靠 GPS 点位。

## 办事流程

- [ ] 校园卡、请假、报修、证明等流程逐项取得官方依据。
- [ ] 材料、地点、电话、费用、时限分别核验。
- [ ] 没有依据的流程保持 needs_verification，Agent 不返回为正式答案。

## 发布复核

- [ ] 管理员审计日志出现对应实体和动作。
- [ ] 普通用户前台显示来源、状态与更新时间。
- [ ] 饭堂页仍明确“无可靠今日菜单”。
- [ ] 外部导航链接指向正确校区。
