# 三校数据核验清单

用途：管理员在把 `historical_seed`、`demo_fixture` 或 `needs_verification` 提升为 `verified` 前，逐项记录来源与实地结果。每个勾选项都应附来源链接/现场记录、核验人、`verified_at` 和置信度。

## 广州校本部

- [ ] 全部饭堂的正式名称、别名、所在区域、楼层和出入口。
- [ ] 每个饭堂的在营档口、餐饮类型、常见餐品、价格区间、餐段、支付方式和核验日期。
- [ ] 教学楼、实验楼、图书馆、宿舍、体育场馆的名称、别名和坐标。
- [ ] 医务室、快递点、超市、ATM、打印点、校园卡服务点、行政办事点。
- [ ] 所有校门、可用导航地址和精确 GPS。
- [ ] 校园底图的版本、授权、坐标方向与更新日期。

## 肇庆校区

- [ ] 全部饭堂的正式名称、校内别名、区域、楼层和坐标。
- [ ] 每个档口的营业状态、餐饮类型、常见餐品、价格、餐段和支付方式。
- [ ] 教学楼、图书馆、宿舍、体育场馆的完整清单与坐标。
- [ ] 医务室、快递点、超市、ATM、打印点、校园卡服务点、行政办事点。
- [ ] 所有校门和公共交通接驳位置的导航入口。
- [ ] 校园底图的版本、授权、坐标方向与更新日期。

## 清远校区

- [ ] 全部饭堂的正式名称、校内别名、区域、楼层和坐标。
- [ ] 每个档口的营业状态、餐饮类型、常见餐品、价格、餐段和支付方式。
- [ ] 教学楼、图书馆、宿舍、体育场馆的完整清单与坐标。
- [ ] 医务室、快递点、超市、ATM、打印点、校园卡服务点、行政办事点。
- [ ] 所有校门和公共交通接驳位置的导航入口。
- [ ] 校园底图的版本、授权、坐标方向与更新日期。

## 通用验收

- [ ] 来源标题、发布机构、URL、发布日期、抓取时间和来源等级已录入。
- [ ] 已区分真实 GPS 和 0–1 示意坐标。
- [ ] 营业时间用可解析格式记录，并设置可配新鲜度阈值。
- [ ] “今日菜单”有当日可核验来源；否则只保留常见餐品且显示警告。
- [ ] 错误修改可从 `location_versions` 回滚，错误条目通过 `is_active=false` 停用。
- [ ] 学生纠错先进 `pending`，不直接覆盖正式数据。
