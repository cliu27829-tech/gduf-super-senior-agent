# 真实校园点位核验待办

内置 JSON 只是历史来源线索和数据模型占位，不能当作完整的实时校园地图。下列条目应由各校区管理员通过官方公开信息与实地核验补齐。

## 广州校本部

- 饭堂楼层、档口、常见餐品、价格区间、营业时间、支付方式和营业状态。
- 教学楼、实验楼、图书馆、宿舍、体育场馆、校门的 GPS 或校园图坐标。
- 医务室、快递站、超市、校园卡服务、ATM、打印点和行政办事点。

## 肇庆校区

- 所有饭堂名称、楼层、档口、营业时间和最近核验状态。
- 教学、住宿、图书、运动、医疗、物流、购物、办事与出入口点位。
- 现有校区图的授权状态与可重用坐标系。

## 清远校区

- 所有饭堂名称、楼层、档口、营业时间和最近核验状态。
- 教学、住宿、图书、运动、医疗、物流、购物、办事与出入口点位。
- 现有校区图的授权状态与可重用坐标系。

## 验收规则

- 每条必须带来源、来源等级、核验方式、核验时间、置信度和数据状态。
- 相对示意坐标不得冒充 GPS；导航前必须显示精度。
- 今日菜单必须来自当日可核验源；否则只展示最近核验档口并明示警告。
- 新数据先进待审核状态，不得由爬虫直接覆盖已核验事实。
